## Problem datasets

1. **Disused coal tips count table (Annex 1 Table 2).** The annex PDF and the coal-tip-safety page carry no licence statement. The gov.wales site-wide copyright statement offers OGL for website content, but the counts come from the national disused coal tips dataset, whose booklet credits Landmark Information Group and the Mining Remediation Authority with all rights reserved, and the map dataset is marked personal use only. Flagged `licence_problem: true`. Nothing has been removed. Action: ask Welsh Government (the annex author is in the Cabinet Division) to confirm in writing that the count table is OGL, or remove the figures before going public.

## Cautions

- **BGS landslide index.** The OGC API collection says the data is "delivered under the Open Government Licence". The older GeoIndex metadata record for the same layer still carries a generic NERC copyright notice with no reproduction without permission, and the BGS guide page gives no licence. Only the free index is covered; the full database is premium. The repository stores only records filtered to tip-related text, so keep to the index. Consider a short confirmation from ipr@bgs.ac.uk. The attribution string is the one already used in the place files; BGS's own pages only ask for acknowledgement of reproduced BGS materials.
- **Terrain tiles, GB coverage.** The Joerd list gives "United Kingdom terrain data © Environment Agency copyright and/or database right 2015" for the UK LIDAR composite, which covers England. Welsh tiles are expected to come from EU-DEM and SRTM, so the Copernicus and USGS lines above are the ones that apply. If the app shows terrain near the English border, add the Environment Agency line.
- **StatsWales.** The new StatsWales (beta) pages show a data provider but no licence. The OGL position rests on the gov.wales copyright statement. Statistics pages on the old StatsWales site stated OGL per dataset.
- **Place JSON `sources` blocks.** model/data/places/rhondda.json and bethesda.json still say the flood layer and WIMD 2019 are "licence field blank" or "believed OGL, verify". These files were out of scope for this pass. The DataMapWales pages now show OGL for both.
- **Logos and third party material.** OGL excludes logos. Nomis states its permission does not extend to third-party material on its site.
