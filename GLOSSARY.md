# Glossary

Use these words exactly, in code, copy and docs. Welsh in brackets is the in-game term (draft, for review).

| Term | Meaning |
|---|---|
| **Etifeddiaeth** | The game. "Inheritance: a game of Wales." |
| **Ddoe / Heddiw / Yfory** | The past (v1.1), the present atlas, the playable future. |
| **Term** (Tymor) | One four-year turn, the engine's step. v1 has six: 2026 to 2046. |
| **Generation** (Cenhedlaeth) | 25 years; the short mode is one generation, ending 2050. |
| **Strand** (Edefyn) | One of the seven well-being goals, shown as 0 to 10 pips of yarn: prosperous, resilient, healthier, equal, cohesive, culture, global. |
| **Pip** | The unit of change on a strand, a cost, or a delay. Never a precise number. |
| **Trust** (Ymddiriedaeth) | The ruler's licence to act; sets how many cards you may play. Not a strand. |
| **Caretaker** (Gofalwr) | Plays one term on defaults if Trust collapses. |
| **Lived** (Wedi'i fyw) | How people fared during your terms. |
| **Left** (Wedi'i adael) | What the 2050 generation inherits. |
| **Result** | The lower of Lived and Left. |
| **Card** (Cerdyn) | A policy lever you play, drawn as a railway ticket. Has cost, delay, scope, effects, side effects. |
| **Curveball** (Pelen gromlin) | An event from the horizon-scan trends; drawn as a slip, not a ticket. |
| **Scope** | Where a card applies: national, region, authority (LA) or place. |
| **Region** (Rhanbarth) | North, Mid, South West, South East. |
| **Authority** (Awdurdod) | One of the 22 local authorities; the model's spatial unit. |
| **Place** (Lle) | An authored zoom view (the Rhondda, Dyffryn Ogwen) with its own real data and decision. |
| **Visit** (Ymweliad) | Spending the term's attention on a place; one per term. |
| **Grade** | Poorly, adequately or well: the result of a place decision, scaling a card's effect. |
| **Indicator** (Dangosydd) | A real measured quantity per authority (e.g. employment rate), with a source. |
| **Stock** (Stoc) | A quantity that carries over time with delays (e.g. coal tip liability, woodland maturity). |
| **Rule** (Rheol) | One relationship in the model, written as data with a kind, parameters, sources and confidence. |
| **Rule kind** | linear, saturating, stock, threshold, fcm, io. |
| **Confidence** | High, medium or low, how sure the evidence is. |
| **Evidence grade** | assessed (in SoNaRR or official statistics), published, expert, placeholder. |
| **Lens** (Lens) | An indicator shown as a tint on the atlas map. |
| **Pull the thread** (Tynnu'r edau) | Tracing a change back through the cards and rules to the sources. |
| **Thread** (Edau) | The player's own changes, stitched onto the paper map. |
| **Model book** (Llyfr y model) | The public, readable list of every rule, indicator and source. |
| **Modified rule set** | Any parameter changed from default; always shown with a badge. |
| **Voice** (Llais) | A one-line, illustrative quote from a real place each term. |
| **Letter** (Llythyr) | The 2050 generation's verdict at the end. |
